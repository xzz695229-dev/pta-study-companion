# 常见问题

[返回首页](../README.md)

| 现象 | 优先检查 |
| --- | --- |
| 双击启动器后缺文件 | 完整解压 ZIP；`bridge.py`、`manager.html`、`requirements.txt` 和启动器需要在同一目录 |
| 缺 Python / pip 安装失败 | 安装 Python 3.10+ 并加入 PATH；查看控制台具体错误，确认可连接包索引 |
| 端口 1455 被占用 | 关闭旧辅助程序；如 CLI 登录占用同一端口，先关辅助程序再登录 CLI。也可通过启动参数换空闲端口，并同步脚本地址 |
| 脚本连不上本机 | 控制台是否还开着；地址/配对码是否匹配；脚本猫和浏览器是否允许访问本机网络 |
| 模型列表只有 Luna | 在设置页向下找到「读取账号模型并检查连接」并点击，查看返回的模型数量或错误。CLI 安装不会自动刷新目录 |
| 切换后模型没变 | 停止任务、选择模型并保存；检查 PTA 脚本设置，不要只修改管理页测试设置 |
| HTTP 403 / 无权限 | 检查账号、地区、工作区及功能资格；重新登录不能保证授予权限 |
| 配额不足 / usage_limit_exceeded | 到官方用量页检查账号和应用限额；不要连续重试生成 |
| HTTP 200 但任务失败 | 需要完整成功事件；HTML、半段输出、断流和错误事件不能当作成功答案 |
| 查询提示找不到 Codex CLI | CLI 是额度查询的可选依赖。安装并登录同一账号，重开终端和辅助程序，执行 `where.exe codex` 检查 PATH |
| PowerShell 报 `\codex.cmd` 找不到 | `$codexDir` 在当前窗口为空。重新执行路径定义，或使用包含 `$env:LOCALAPPDATA` 的完整路径 |
| npm 报 EPERM 创建目录失败 | 当前目录不可写或被安全软件拦截。优先使用当前用户目录安装，见使用指南；不要给整个磁盘放开权限 |
| Codex 账号不一致 | CLI 与辅助程序分别核对账号；换成相同邮箱再查询。多工作区需自行确认，程序无法独立验证 |
| 额度括号是（—）或变化为零 | 首次/重置后无可比数据；15 秒缓存；服务端百分比可能有取整，零变化不代表完全没消耗 |
| DeepSeek 没显示钱 | 尚无回执、缺少完整 usage 或模型单价未知。未知不是免费；以官方账单为准 |
| 反复失败仍在重试 | 确认是否在 DeepSeek 路线，保留的旧重试规则可能持续重试；先停止，再排查根因 |
| 浏览器可访问而辅助程序连不上 | 管理页填写实际 HTTP 代理地址；不要猜端口，不要把密码/密钥放进问题截图 |
| 菜单/界面没更新 | 脚本猫检查版本应为 0.11.1，停用重复版本后刷新 PTA |

如需提 Issue：描述题型和复现步骤，附版本、脱敏错误与截图。不要上传 Key、配对码、OAuth 凭据、邮箱或管理页含口令的 URL。服务端已开始的失败/取消请求仍可能计入消耗。
